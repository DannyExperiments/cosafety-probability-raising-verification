# The equality test

Extract the ZIP and open index.html locally. Change the chance of the effect from z and the chance of choosing action B. Drag sideways or focus the diagram and use the arrow keys to rotate the projected state markers.

The only cause word is s,t. From s, action A goes to z and action B goes to t or f with probability one-half each. The effect chances from t and f are 1/2 and 0. The selected scheduler is tested only if the word has positive mass. The whole candidate passes exactly when every scheduler giving the word positive mass strictly raises the effect probability.

The GIF contrasts the relaxed equality at a zero-mass word with an actual violating tie. Increasing z's effect chance from 1/2 to 3/4 is enough that an even choice between A and B makes the overall probability equal the conditioned probability, with cause word mass 1/4.

Use Python 3.11 or newer and Pillow 10.1 or newer. Run python3 visualization/render.py from the repository root to rebuild the looping GIF and the offline ZIP.
